# Contributing to Emoji Vault 💜

Thanks for your interest in Emoji Vault!

## Reporting bugs

Please open a GitHub issue and include:
- What you were trying to do
- What you expected to happen
- What actually happened
- Your Windows version and Emoji Vault version

Don't include passwords, private data, or personal emoji collections in reports.

## Suggesting features

Open an issue describing your idea and why it would be useful. Please check existing issues first to avoid duplicates.

## Contributing code

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes and test them.
4. Submit a pull request explaining what you changed.

Please keep changes focused and avoid committing build output, dependencies, personal data, or secrets.

Thanks for helping make Emoji Vault better! 💜
